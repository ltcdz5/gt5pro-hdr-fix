# 横屏 HDR 表候选

反馈：「刷完模块开启 HDR 后亮度还是会变暗」。

实测原因：当前发布的 `module/ghdr_lut.bin`（横屏表）在白点处把 R/G 压掉了约 20%：

```
原始表  白点 R=4085 G=4076 B=4067  Y=0.9902
当前表  白点 R=3232 G=3297 B=4095  Y=0.6348   ← 暗 35.9%
```

因为白点处 B 已到 4067/4095，几乎没有上抬空间；要更蓝只能压 R/G，于是高光被压掉三分之一。
中低段反而有余量，补蓝后亮度还略升（gray Y 0.2068 → 0.2184）。

## 候选（均基于横屏原表重建，B 增益 1.30）

| 文件 | 白点 B/R | 白点 Y | 相对原表 |
|---|---|---|---|
| land_A_亮度优先.bin | 1.002 | 0.9913 | +0.1% |
| land_B_折中6pct.bin | 1.066 | 0.8707 | −12% |
| land_C_12pct.bin | 1.139 | 0.7602 | −23% |
| land_D_接近现状.bin | 1.253 | 0.6273 | −37% |

A 不压 R/G，亮度完全保持，中低段补蓝到位，但纯白高光仍偏黄；
越往后高光越蓝、也越暗。

## 怎么试（不用刷机）

```sh
# 推到手机
adb push land_A_亮度优先.bin /sdcard/land_A.bin

# 写入（root）
su -c 'cat /sdcard/land_A.bin > /proc/sdehdrlut_land'

# 退出 HDR 再进一次才生效
```

`cat /proc/sdehdrstat` 可看命中次数。
